Included once, from base.html, so it is available on every page for logged-in users: pressing it anywhere shows either the live progress of a running refresh or the result of the last one (interrupted, failed or finished). Progress is short-polled (analyst.refresh_progress) rather than SSE, so a refresh never holds a gunicorn thread for the 5-10 minutes it runs.
